# Why there is no application front end

The recurring work is reviewing records: a content plan, a human decision tied to its exact revision, source evidence and exported results. The coding agent operates the CLI. Read-only branded HTML gives the team a calendar review, campaign brief and performance snapshot.

A social publishing screen also gives mobile use, image and video previews, drag-and-drop planning, live inbox handling and network publishing. This free build does not provide those experiences. It does not replace a social network, listening data or its access permissions. Exports must be refreshed by the operator.

Enterprise DNA scopes the required connections, review screens and publishing approvals in a custom version. The base remains a database and commands. Generated HTML is a snapshot; regenerate it after changing records.
